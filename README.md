# Hagia Sophia Design Studio — Clean Start

A minimal scaffold to build your site from the ground up. Keep it simple, iterate fast.

## Files
- `index.html` — Semantic, minimal HTML with header, main, and footer
- `style.css` — Tiny base styles with brand color token `#025959`

## Customize
- Update the title and description in `index.html`
- Use the `.section` blocks to add content areas
- Use `.container` to keep content aligned
- Buttons: `.btn` and `.btn--primary`

## Next steps
- Add a simple nav and placeholder sections (About, Work, Contact)
- Create a basic grid helper if you need columns
- Drop in your logo SVG and set `.logo {}` styles
- If you have typography guidelines, add font imports and type scale

## Dev tips
Just open `index.html` in your browser. No build tools required. If you want live reload, serve the folder with a simple static server.
